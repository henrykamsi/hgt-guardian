Welcome to HGT Guardian

Ensure maximum threat mitigation before users interact with your sensitive endpoints. The HGT Guardian acts as a permanent, timer-less cognitive and biometric gate.

Perfect for Forms: You can trigger this verification layer immediately when a user attempts to access a Sign Up form or a Login form, preventing automated credential stuffing, bots, and brute-force attacks.

Web / HTML Integration

To protect your login, signup, or main website, paste this initialization code inside the <head> tag of your HTML document. The script will intercept the page load until the user verifies their identity.

index.html (Head) 
<!-- HGT Guardian Platform Injection Core -->
<script src="https://henrykamsi.github.io/hgt-guardian/hgt-guardian.js"></script>
<script>
    window.addEventListener('DOMContentLoaded', function() {
        HGT_Guardian.init({
            brand: 'Your App Name',
            mode: 'full', 
            autoGuard: true,
            onSuccess: function() {
                // Unlocks the login/signup form or redirects
                console.log("User verified.");
                document.getElementById('login-form').style.display = 'block';
            }
        });
    });
</script>

Android App Integration

When loading your HTML forms inside a Kotlin WebView, you must intercept the authentication status using a Javascript Interface. This allows the web security layer to talk directly to your Android Native OS.

MainActivity.kt 
import android.webkit.JavascriptInterface
import android.webkit.WebView
import org.json.JSONObject

class HGTGuardianRuntimeBridge(private val webView: WebView) {
    @JavascriptInterface
    fun postMessage(message: String) {
        val payload = JSONObject(message)
        val status = payload.optString("status") 
        
        if (status == "VERIFIED") {
            // User passed the Guardian Check
            // Load native sign-up screen
        } else if (status == "DECLINED") {
            // Lock out user
        }
    }
}
// Attach via: webView.addJavascriptInterface(HGTGuardianRuntimeBridge(webView), "AndroidBridge")

iOS Swift Integration

For iOS apps using WKWebView, utilize the WebKit Script Message Handler to listen for the validation events dispatched by the HGT Guardian engine.

ViewController.swift 
import WebKit
import UIKit

class SecurityViewController: UIViewController, WKScriptMessageHandler {
    func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
        if message.name == "iOSBridge", 
           let dictionary = message.body as? [String: Any],
           let status = dictionary["status"] as? String {
            
            if status == "VERIFIED" {
                // Biometrics and math checks passed
                // Proceed to native login form
            } else if status == "DECLINED" {
                // Reject access
            }
        }
    }
}
