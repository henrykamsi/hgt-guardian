Web Integration

Implement the HGT Guardian on your HTML/JS websites to stop bots before they load your content.

1. First Redirect (Gatekeeper)

This code ensures that when users click your website link, they must verify they are human before any content is sent. Place this inside your <head>.

index.html (Head)
<style> body { display: none; } /* Hides site until verified */ </style>
<script src="https://henrykamsi.github.io/hgt-guardian/hgt-guardian.js"></script>
<script>
    HGT_Guardian.init({
        brand: 'Your App',
        mode: 'full',
        onSuccess: function() { document.body.style.display = 'block'; }
    });
</script>

2. Login Verification

This code protects your login form. The form is invisible until the user passes the security check.

login.html
<div id="hgt-login" style="display:none;">
    <form>
        <input type="email" placeholder="Email">

Android OS Integration

Use these Kotlin/Java bridges to trigger the native Android UI after the web-based security layer is passed.

1. First Redirect (Gatekeeper)

Intercepts the first app launch, holding the native UI until the WebView sends the VERIFIED signal.

MainActivity.kt / .java
// KOTLIN
webView.settings.javaScriptEnabled = true
webView.addJavascriptInterface(HGTBridge(this), "HGTBridge")

class HGTBridge(val context: Context) {
    @JavascriptInterface
    fun postMessage(status: String) {
        if (status == "VERIFIED") { /* Remove Loading Screen, Show Home */ }
    }
}

// JAVA
webView.getSettings().setJavaScriptEnabled(true);
webView.addJavascriptInterface(new HGTBridge(this), "HGTBridge");

public class HGTBridge {
    Context mContext;
    HGTBridge(Context c) { mContext = c; }
    @JavascriptInterface
    public void postMessage(String status) {
        if (status.equals("VERIFIED")) { /* Remove Loading Screen, Show Home */ }
    }
}

4. Master Code (Combination)

A global Application-level bridge that handles routing for Gatekeeper, Login, and Signup dynamically.

GlobalHGTBridge.kt
class GlobalHGTBridge(private val activity: Activity, private val viewType: String) {
    @JavascriptInterface
    fun postMessage(status: String) {
        if (status == "VERIFIED") {
            activity.runOnUiThread {
                when(viewType) {
                    "GATEKEEPER" -> showMainAppUI()
                    "LOGIN" -> showLoginUI()
                    "SIGNUP" -> showSignupUI()
                }
            }
        }
    }
}
// Usage: webView.addJavascriptInterface(GlobalHGTBridge(this, "SIGNUP"), "HGTBridge")

iOS Swift Integration

Utilize WebKit Handlers to manage the Apple iOS native UI based on HGT Guardian signals.

1. First Redirect (Gatekeeper)

Blocks the initial View Controller progression until verification is completed.

SceneDelegate.swift
func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
    if message.name == "HGTBridge", let status = message.body as? String {
        if status == "VERIFIED" {
            // Transition from Launch Screen to Main Tab Bar Controller
            self.transitionToMainApp()
        }
    }
}

2. Login Verification

Unlocks the native SwiftUI / UIKit Login TextFields.

LoginViewController.swift
func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
    if message.name == "HGTBridge", let status = message.body as? String {
        if status == "VERIFIED" {
            DispatchQueue.main.async {
                self.emailTextField.isHidden = false
                self.passwordTextField.isHidden = false
                self.loginButton.isHidden = false
            }
        }
    }
}

3. Sign Up Verification

Unlocks the native Sign Up TextFields (Name, Surname, Email, Password).

SignupViewController.swift
func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
    if message.name == "HGTBridge", let status = message.body as? String {
        if status == "VERIFIED" {
            DispatchQueue.main.async {
                self.signupFormStackView.isHidden = false
            }
        }
    }
}

4. Master Code (Combination)

A unified Handler extension that processes all HGT signals app-wide.

HGTManager.swift
extension UIViewController: WKScriptMessageHandler {
    public func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
        guard message.name == "HGTBridge", let status = message.body as? String, status == "VERIFIED" else { return }
        
        DispatchQueue.main.async {
            if self is LoginViewController { (self as! LoginViewController).unlockForm() }
            else if self is SignupViewController { (self as! SignupViewController).unlockForm() }
            else { self.dismiss(animated: true) } // Default Gatekeeper unlock
        }
    }
}
